Kroxylicious 0.25.1 has been released with critical security fixes.

This is a security-focused patch release addressing one vulnerability in Kroxylicious and multiple vulnerabilities in Netty.

---

### Security Advisories

#### CVE-2026-105941: SSRF in Azure Key Vault KMS Provider

**Affected:** Kroxylicious when using the Record Encryption filter configured with the Azure Key Vault KMS provider.

**Not affected:** If you are not using the Record Encryption filter, or if you are using Record Encryption with a different KMS provider (AWS KMS, HashiCorp Vault, Thales CipherTrust Manager, etc.), you are not affected by this vulnerability.

**Description:** The Azure Key Vault KMS provider deserializes the `vaultName` field from Encrypted Data Encryption Keys (EDEKs) embedded in Kafka records without proper validation, creating a Server-Side Request Forgery (SSRF) vulnerability.

A malicious actor with write access to a Kafka topic can craft a record containing a specially constructed EDEK that causes the proxy to direct Key Vault HTTP requests—including Azure bearer token Authorization headers—to an attacker-controlled server. An attacker in possession of a stolen bearer token can then use it directly against the real Azure Key Vault to decrypt any EDEK, enabling full decryption of Kafka records protected by the Record Encryption filter.

The root cause is a trust boundary confusion: the proxy's configuration strictly validates vault names at startup, but the vault name embedded in EDEKs is validated only with an `isBlank()` check, allowing special characters like `.`, `/`, and `#` that bypass the URL parsing and redirect requests to attacker-controlled hosts.

**Fix:** The Azure Key Vault KMS provider now validates the `vaultName` field in EDEKs using the same strict pattern applied to the configured vault name, preventing maliciously crafted vault names from being used.

**Advisory:** [GHSA-5j25-p663-ww5r](https://github.com/kroxylicious/kroxylicious/security/advisories/GHSA-5j25-p663-ww5r)

### Netty Security Updates

Kroxylicious 0.25.1 upgrades Netty from 4.2.18.Final to **4.2.19.Final**, which addresses 16 security vulnerabilities.
Details of all fixed vulnerabilities are available in the [Netty 4.2.19.Final release notes](https://github.com/netty/netty/releases/tag/netty-4.2.19.Final).
